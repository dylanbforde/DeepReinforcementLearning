## 2025-02-15 - [Optimizating PyTorch Soft Updates and Gradient Zeroing]
**Learning:** In PyTorch, target network soft updates using `param.data.copy_(TAU * policy_param + (1 - TAU) * param.data)` create temporary tensors which are extremely slow and CPU/GPU memory inefficient. Using the in-place `.lerp_` method (`target_param.data.lerp_(policy_param.data, TAU)`) avoids intermediate allocations and provides significant (~17x) performance boosts for these frequent operations. In addition, using `.zero_grad(set_to_none=True)` clears gradients without overwriting the memory, which is faster than the default zeroing.
**Action:** When working on PyTorch DQN implementations, automatically check the `optimize()` or `update()` logic for soft network updates and gradient zeroing to switch to `.lerp_()` and `.zero_grad(set_to_none=True)` respectively.

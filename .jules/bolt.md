## 2024-11-20 - PyTorch In-Place Linear Interpolation
**Learning:** In PyTorch, using explicit arithmetic for soft parameter updates (e.g., `target.data.copy_(tau * policy.data + (1 - tau) * target.data)`) causes unnecessary intermediate tensor allocations. This is highly inefficient in hot paths like RL training loops.
**Action:** When updating target networks or performing exponential moving averages, use the built-in in-place interpolation method `.lerp_()` (e.g., `target.data.lerp_(policy.data, tau)`). It leverages optimized C++ kernels and avoids intermediate memory allocations, leading to measurable speedups. Furthermore, pairing this with `optimizer.zero_grad(set_to_none=True)` slightly speeds up backward passes and reduces memory fragmentation compared to zeroing out gradients manually.

## 2026-05-01 - PyTorch Soft Update Optimization\n**Learning:** In PyTorch, using `target_param.data.copy_(self.TAU * policy_param.data + (1.0 - self.TAU) * target_param.data)` creates multiple intermediate tensors. This is a common performance bottleneck in reinforcement learning codebase architectures.\n**Action:** Always prefer the mathematically equivalent in-place method `target_param.data.lerp_(policy_param.data, self.TAU)` to minimize memory allocations and improve training loop performance.
